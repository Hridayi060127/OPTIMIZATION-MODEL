TITLE - Business Optimization Using Linear Programming with Python
This project focuses on solving a real-world business decision-making problem using optimization techniques, specifically Linear Programming (LP). The main objective of the project was to determine the best production strategy for a company that manufactures two products, Product A and Product B, while working with limited resources. In many businesses, resources such as labor hours, machine capacity, raw materials, and production time are limited. Making the right decisions about how to use these resources efficiently is essential for maximizing profits. This project demonstrates how mathematical optimization can help solve such business challenges.

In this project, we considered a business scenario where a company produces two products with different profit values and resource requirements. Product A generates higher profit per unit but requires more machine time, while Product B generates slightly lower profit but uses resources more efficiently. The goal was to determine how many units of each product should be manufactured in order to achieve the maximum possible profit while staying within the available machine and labor constraints.

To solve this problem, Linear Programming was used. Linear Programming is a mathematical method used to optimize an objective function, such as profit maximization or cost minimization, subject to a set of constraints. In this project, the objective function was to maximize total profit, and the constraints represented the limited availability of machine hours and labor hours.

The project was implemented using Python, one of the most widely used programming languages in data analysis, business analytics, and optimization. The main library used was PuLP, a Python library designed for solving linear programming and optimization problems. PuLP allowed us to define decision variables, set the objective function, add constraints, and compute the optimal solution efficiently.

The development and execution of this project were carried out using Google Colab, a cloud-based notebook platform that allows users to write and run Python code directly in a web browser without installing software locally. Google Colab was chosen because it provides an easy-to-use interactive environment, automatic saving, and support for Python libraries, making it suitable for academic and analytical projects.

After implementing the model, the optimization results showed the ideal production quantities of both products along with the maximum achievable profit. A what-if analysis was also performed by changing one of the constraints, specifically labor availability, to observe how the optimal production strategy changes under different business conditions. This helped demonstrate how optimization models can support strategic planning and decision-making.

This type of optimization project has practical applications across multiple industries. In manufacturing, it can help companies decide the best product mix. In supply chain management, it can optimize transportation and inventory decisions. In finance, it can support budget allocation and investment planning. In retail and operations management, it can improve resource utilization and profitability.
Overall, this project successfully demonstrates how optimization techniques, combined with Python-based analytical tools, can be used to solve business problems, improve efficiency, and support data-driven decision-making in real-world scenarios.
